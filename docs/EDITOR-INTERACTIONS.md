# 編集画面の入力操作

既定のキーを別の用途に割り当てない。ブラウザが優先するキーには画面操作か代替キーを用意し、ネイティブ版の割り当ては変えない。入力欄の編集中は、文字入力と通常のカーソル移動をショートカットが奪わない。IME変換中とモーダル表示中は編集画面へのキー操作を止める。

表中のCtrl操作はCommand（Cmd）でも使える。macOSではCommandを使い、やり直しはCmd+Shift+Zでも行える。ホイール操作も同様。OSが優先する組み合わせはメニュー・ボタンから操作する。macOSでFキーがシステム操作に割り当てられている場合はFnを併用する。

## 音声パネル

| 操作 | 動作 |
| --- | --- |
| F1・F2・F3・F4・F5 | 左ブランク・オーバーラップ・先行発声・固定範囲・右ブランクをポインター位置へ設定。保持中は追従し、解放で確定 |
| Alt+F1・Alt+F3 | 対応する連動が有効な場合、同じWAVの隣接行にも移動量を反映 |
| Shift+P・Shift+L | 先行発声・左ブランクの連動方式を切り替え |
| Ctrl+Shift+L | 左ブランクだけを動かす位置保持方式へ変更 |
| 2・J・S・下、8・K・W・上 | 次行、前行 |
| F6・F7、Ctrl+F6・Ctrl+F7 | 次行、前行 |
| Alt+F6・Alt+下、Alt+F7・Alt+上 | 次のWAV、前のWAV |
| 4・A・H・左、6・D・L・右 | 表示幅の10%を左右へスクロール |
| PageUp・PageDown | 表示幅の90%を左右へスクロール |
| Q | 先頭へスクロール |
| F11・F12 | ポインターを基準に1.5倍ずつ縮小・拡大 |
| C | WAVを再読み込み |
| Space・5・Ctrl+P | 全体再生。再生中は停止 |
| Ctrl+Space・Ctrl+Alt+P | 左ブランクから右ブランク（または末尾）まで再生。再生中は停止 |
| Ctrl+Shift+Space | 表示の左端から末尾まで再生 |
| Ctrl+F1〜F5 | 設定した開始点・終了点で再生 |
| F8 | 発声タイミング試聴。再度押すと停止 |
| F9 | 「WAVのカットを許可」が有効なら、選択WAVのブランク外カットを確認して実行 |
| F10 | 割り当てなし |
| Esc | 再生を停止 |

- マーカーの設定は音声パネル内のポインター位置を対象にし、時間軸やスクロールバー上では設定しない。
- 近傍区間再生モードでは、背景クリックより厳密に前・後にある最も近いマーカー間を再生する。該当するマーカーがなければファイルの先頭・末尾を使う。マーカーのドラッグには区間再生を重ねない。
- ほうきモードでは、波形のクリック・ドラッグで先行発声を設定する。近傍区間再生モードと同時に有効にしない。
- 中クリックは、左ブランクなら先頭から左ブランクまで、それ以外のマーカーなら左ブランクからそのマーカーまで再生する。Ctrl+F1〜F5の設定とは独立する。
- ホイールは音声パネル内で行移動、それ以外で横スクロール。Altを押しながらでWAV移動、Shiftで横スクロール、Ctrlでポインター基準のズーム、Ctrl+Shiftで対象パネルの高さを20ずつ変更（上回転で縮小、下回転で拡大）。
- パネル間の境界はドラッグと矢印キーで高さ配分を変える。境界にフォーカスがある間は矢印キーを行移動より優先し、境界線上のポインター操作はマーカー操作よりリサイズを優先する。
- 時間軸の左クリックで秒／小節を切り替え、右クリックでBPM・開始位置の画面を開く。
- 部分読み込み中も、座標・時間軸・編集値は元WAVの先頭を基準にする。

## 一覧とセル入力

| 操作 | 動作 |
| --- | --- |
| クリック | セル入力を開始 |
| ドラッグ | セルの矩形選択 |
| Tab・Shift+Tab、Alt+右・左 | 次・前のセルへ移動 |
| Enter・下・Ctrl+J、上・Ctrl+K・Ctrl+U | 次・前の行へ移動 |
| 左・Ctrl+H・Ctrl+B | カーソルを左へ移動。先頭では前のセルへ移り、末尾にカーソルを置く |
| 右・Ctrl+L | カーソルを右へ移動。末尾では次のセルへ移り、先頭にカーソルを置く |
| Space | 編集中の文字入力 |
| Shift+Space・Ctrl+P | 全体再生 |
| Ctrl+C・Ctrl+X・Ctrl+V | 選択セルのコピー・切り取り・貼り付け |
| Ctrl+M | 条件付き一括変更 |
| Ctrl+I | 単一行の複製 |
| Ctrl+D | 単一行の削除。同じWAVの最後の行は削除しない |
| 右クリック | 一覧のメニュー（一括変更など） |

- 数値入力は空欄と「-」の途中入力を許し、空白文字と数値以外を拒否する。上限は絶対値1,000,000、小数は3桁。入力ごとに編集状態へ反映し、別の行をクリックしたら確定する。
- 左ブランクの直接入力と貼り付けは、位置保持モードでは他のマーカーの絶対位置を保つ。
- コピーはWAVの拡張子を除いた名前と選択セルを設定の区切り形式で出力し、末尾に改行を付ける。切り取りは数値セルを空欄にする。
- 貼り付けは選択範囲に行列を繰り返し、単一値は範囲全体へ適用する。行列の大きさが合わない場合は確認する。

## 共通

| 操作                                | 動作               |
| ----------------------------------- | ------------------ |
| Ctrl+O                              | iniの読み込み      |
| Ctrl+S                              | 保存               |
| Ctrl+Shift+S                        | 別名保存           |
| Ctrl+F                              | 検索欄へ移動       |
| Ctrl+G・Ctrl+N（Shift併用で逆方向） | 次（前）の検索結果 |
| Ctrl+Z                              | 元に戻す           |
| Ctrl+Y・Ctrl+Shift+Z                | やり直す           |

保存・検索・元に戻す／やり直すは入力欄の編集中も使える。

## メニューと設定画面

上部のメニューは「ファイル」「表示」「オプション」「ツール」。階層メニューで、選択中の項目にはチェックを表示する。

| メニュー | 内容 |
| --- | --- |
| ファイル | 音源フォルダを開く、最近使ったフォルダ、iniの読み込み、上書き保存、名前を付けて保存、設定ファイルの読み込み・書き出し |
| 表示 | 波形・スペクトログラム・パワー・F0の表示切り替え、横軸の拡大・縮小・全体表示、時間軸。ネイティブ版は最前面表示と透過 |
| オプション | マウス・キー操作、右ブランクの表現、発声タイミング、指定範囲再生、再生追従・位置復帰、自動フォーカス・次行移動、セルのコピー形式、設定の自動保存、詳細設定 |
| ツール | 原音設定の自動推定、WAVの一括編集、仕上げ・補完、並び替え、エイリアス一括変更、原音設定の一括処理（検索・置換・抽出、規則でエイリアスを複製・置換、重複エイリアスの整理、先行発声・オーバーラップの調整、連続音からCV・VCを追加） |

- 数値の一括変更はCtrl+Mか一覧の右クリックから開く。ヘッダーに一括変更のボタンは置かない。
- 詳細設定は描画・解析条件・色・文字だけを扱う。パネルの表示切り替えは含めず、既定値への復帰で表示切り替えや操作の設定を変えない。
- フォーカス・次行移動・指定範囲再生の画面は変更時に適用し、「閉じる」で終える。詳細設定と発声タイミングの画面は「適用」「OK」「キャンセル」を使う。クリック音の選択も適用するまで確定しない。
- ダイアログは見出しを固定して本文だけをスクロールする。
