# 受け入れ条件

## 必須シナリオ

| 対象 | 合格条件 |
| --- | --- |
| 既存音源 | 実フォルダを開き、既存oto.iniとWAVを読み、1行を編集して保存・再読込できる |
| 新規音源 | oto.iniがないフォルダのWAVから初期行を作り、設定・保存できる |
| 複数エイリアス | 同じWAVの複数行を独立して選択・編集・複製・削除できる |
| 連続音 | 1つの長いWAVの各行を編集でき、先行発声の連動移動が設定どおり動く |
| 音声表示 | 波形・スペクトログラム・マーカーを同じ時間基準で表示し、ズーム後も位置が一致する |
| 試聴 | 全体再生・範囲再生・停止ができ、表示位置と再生範囲が一致する |
| 編集履歴 | 数値入力・エイリアス変更・行の追加削除・連動移動を元に戻す／やり直すことができ、1回のドラッグを1回で戻せる |
| 操作 | F1〜F5、前後移動、拡大縮小、検索、保存が使え、入力欄の文字編集を奪わない |
| 画面 | 原音設定値を色と名前・形で区別し、表示領域を調整できる |
| 設定 | 自動保存ONの変更を起動後に読み戻せる。OFFの変更は起動中だけ適用し、手動保存した内容だけを残す。保存に失敗しても適用中の値と以前の保存内容を失わない |
| フォルダ履歴 | 最近開いた順に重複なく20件を保持し、Webでは保存したフォルダ参照から開き直せる |
| Web・ネイティブ | 両環境で同じ編集ロジックを使い、フォルダ選択から再読込まで到達する |
| 一括処理 | 検索・置換・抽出、規則による複製・置換、重複の整理、先行発声・オーバーラップの調整、CV・VCの追加で、処理前の一覧が適用結果と一致し、1回の「元に戻す」で取り消せる。絞り込み中に隠れた行を変えない。書き出しに失敗したら行を削除しない |
| 自動原音設定 | 日本語CV・VCV・CVVCを実WASMで推定し、結果確認から反映・取り消し・保存へ進める。キャンセル・取得失敗・推定失敗では編集内容を変えない |

## oto.iniの互換

- UTF-8とShift_JIS、LFとCRLF、日本語のファイル名・エイリアスを含むファイルで往復する。
- 未編集のファイルを保存すると元ファイルとバイト一致する。
- 編集した行以外の内容と重複エイリアスを保つ。
- 正負の右ブランクと負のオーバーラップを読み書きし、数値を補正しない。
- 解釈できない行、不正な数値、参照先WAVの欠損を識別でき、削除しない。安全に保存できない編集は理由を表示する。
- 実際のUTAUまたはOpenUTAU用の音源で確認する。

## 保存と復元

- 元ファイルは明示保存でだけ更新し、復元データの記録では更新しない。
- 保存前の内容をバックアップとして残す。
- 他のアプリによる元ファイルの変更を保存前に検知して知らせる。
- 権限失効、読み取り専用、書き込み失敗、バックアップ作成失敗のとき、編集内容と未保存表示が残る。
- 書き込み完了を確認してから保存済みにする。
- 未保存で終了・フォルダ切り替えをするとき、保存・保存しない・キャンセルを選べる。
- 未保存のまま再起動したとき、復元データと元ファイルの関係を確認して復元できる。元フォルダへの再許可が必要な場合も扱う。
- ストレージ不足や復元データの保存失敗を成功扱いにしない。

## 配布

- リリースPRでJS・Tauri・Rust・Cargo.lockのバージョンが一致し、公開タグのコミットから3つのOSの配布物を作れる。
- リリースPRのマージ後、全配布物がそろった場合にだけ自動公開される。ビルド・アップロード失敗時は下書きを保ち、同じタグで再実行できる。
- Web版の起動にTauriランタイムを要求せず、非対応のファイル選択APIを案内する。
- 配布exeは開発用のNode.js・Vite・Rustツールチェーンなしで起動する。
- インストーラー版はRuntime導入済み／未導入の両方で動く（未導入時の導入はオンライン前提）。
- ポータブル版は既存Runtimeを使い、不足時に案内する。
- Runtime導入後のネイティブ版はオフラインで編集を完了できる。
- 選択したフォルダとアプリ自身の設定・復元領域の外へのファイルアクセスを要求しない。
- Windows・macOS・Linuxの各ネイティブ版で、フォルダ選択・編集・試聴・保存・再読込・未保存終了の確認・再起動後の復元ができる。
- Windows x64・ARM64・x86とLinux x64・ARM64・x86の配布物を別々のファイル名で生成し、対象CPUでインストール・起動できる。
- macOSのCommandで保存・元に戻す／やり直す・検索・表のコピー／貼り付け・再生を操作できる。
- Linuxの大小文字を区別するフォルダで、復元データを別々に保持できる。

## 検証の方針

- 自動テストはパーサーと書き戻し、右ブランクの変換、編集履歴、保存失敗・競合など、データ破損に直結する処理を優先する。
- ブラウザとネイティブの実動作確認をモックのテストで代替しない。
- 重い処理は長いWAVと多数の行で確認し、処理中に画面操作が止まらないことを確かめる。
- 実音源はリポジトリに含めない。

## 未確認の項目

- GitHub ActionsでのRelease PleaseのPR作成・バージョン更新・タグ作成・下書き作成から、全OSの配布物のアップロード・自動公開・失敗後の再実行までの一連の動作。
- macOSのapp・DMGとLinuxのdeb・AppImageのビルド、インストール・起動、各ネイティブ版での必須シナリオ。
- Windows ARM64・x86とLinux ARM64・x86のCIビルド、各CPUでのインストール・起動・必須シナリオ。Windows ARM64のNSISとWebView2の導入。
- macOSのWKWebViewとLinuxのWebKitGTKでのWASM・Worker・音声解析・試聴・オフライン編集。
- macOSのCommand操作、Fn併用のマーカー操作、OSのショートカットとの競合。
- Linuxの大小文字を区別する音源フォルダとmacOSの日本語ファイル名での保存・復元。
- SHIRO仮モデルの精度、特に同一母音の連続・撥音・弱い子音の境界と、CV・CVVC実音源での試聴。
- MoreLauncher・moresamplerとのCVVCの設定値と語尾エイリアスの一致。
- Web・ネイティブでの自動推定と音源別学習の全操作、学習中のキャンセル、取得後のオフライン再実行。
- 音素ラベルのネイティブ版での音源フォルダへの保存と、HTK単音素ラベルを扱うツールへの取り込み。

- ブラウザ版で、実際のフォルダ選択ダイアログ（`showDirectoryPicker`）から開いて保存する操作。
- フォルダ経由のiniアクセスが拒否されるブラウザでの、新規iniの作成。
- 音の聴取と、範囲再生の終了位置の精度。
- インストーラーの導入（Runtime導入済み／未導入）、ポータブルexeのRuntime未導入時の案内、オフライン起動。
- 外部フォルダの権限失効と再許可。
- 長いWAVでの処理速度。
- 実音源での、一括処理で作ったCV・VCの区間の試聴と、BPM調整・3:1調整後の発声タイミング。
- 数千行の音源での一括処理の一覧表示と、複雑な正規表現の検索で画面が止まらないこと。
- ブラウザ版の抽出iniの書き出し（フォルダ経由のini書き込みが拒否される場合の保存ダイアログを含む）と、抽出iniを開き直したときのWAV参照。
- ネイティブ版での全ツール・詳細設定の操作と、すべてのキー・マウス操作の境界条件。
