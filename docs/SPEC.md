# 初版仕様

Avennotaの初版はUTAU音源の原音設定エディター。音源フォルダを開き、原音設定行を波形・スペクトログラムで確認・試聴しながら編集し、oto.iniを保存する。再度開いたときに編集結果が一致する。既存oto.iniの修正と新規作成の両方を扱う。

用語は[GLOSSARY.md](../GLOSSARY.md)、機能の一覧は[EDITOR-FEATURES.md](EDITOR-FEATURES.md)、キー・マウス操作とメニューは[EDITOR-INTERACTIONS.md](EDITOR-INTERACTIONS.md)、完成の判断基準は[ACCEPTANCE.md](ACCEPTANCE.md)。

## 対象環境と配布

- ネイティブ版の対象はWindows 11（x64・ARM64）・Windows 10（x86）、macOS 14以降（Apple Silicon・Intel）、Linux（x64・ARM64・x86）。Linux x86の配布基準はDebian 12。Web版は各OSの現行のデスクトップChrome・Edgeを対象とする。
- Web版はHTTPSで公開し、File System Access APIでユーザーが選んだ音源フォルダを直接編集する。APIがない環境では非対応を案内する。Tauri APIを起動時に呼ばない。
- フォルダ経由のiniアクセスが制限された場合は、音源フォルダ直下の既存iniを個別に選ぶ。選択したファイルを読み込み・上書き保存・履歴・復元に使い、一覧に出ないファイルを新規と判断しない。
- Windows版はNSISインストーラーとポータブルexeを配布する。どちらもフロントエンドを含み、WebView2 Runtime導入後はオフラインで編集できる。
- macOS版はapp・DMG、Linux版はdeb・AppImageを配布形式とする。macOSはシステムのWKWebView、LinuxはWebKitGTK 4.1を使う。
- 編集・音声処理・保存・復元は3つのOSで共有する。透過率の設定はWindows版だけに適用する。
- 配布先は`Lqm1/Avennota`のGitHub Releases。Release Pleaseでバージョン・変更内容をまとめるPRを作り、マージ後に全OSの配布ビルドが成功したリリースを自動公開する。
- インストーラーのWebView2導入はTauri既定のdownloadBootstrapper。Runtimeがなければネット経由で導入する。固定Runtimeやオフライン導入用インストーラーは同梱しない。
- ポータブルexeは既存のWebView2 Runtimeを使い、Runtimeもその導入プログラムも同梱しない。WebView生成前に不足を検出し、インストーラー版かMicrosoft公式のRuntime導入を案内する。

## 編集の単位

- 1つのフォルダと1つのoto.iniを編集単位とする。子フォルダのWAVを参照する行は、そのフォルダを個別に開いて編集する。
- 独自プロジェクトファイルは作らない。フォルダを開いたら編集画面に入る。
- 一覧で選ぶ対象は原音設定行。同じWAVに複数の原音設定行を持てる。
- oto.iniがなければWAV一覧から初期行を作る。既存oto.iniにない原音も手動で追加できる。初期行の値は自動推定の結果ではない。

## 画面

- 上部にメニューと最小限の操作、中央に音声パネル、下部に原音設定の一覧とその右の詳細欄、最下部にステータスバーを置く。表示領域の大きさは調整できる。
- 上部はメニュー・元に戻す／やり直す・未登録WAVからの行作成・検索。波形パネル上端は再生・ズーム・マーカー配置・先行発声の連動。ステータスバーは保存状態・行数・通知・文字コード。
- ウィンドウの最小幅は800px。操作列は1段に収め、ボタン単位で折り返さない。幅が足りないときは名前を省いてアイコンだけにする。元に戻す／やり直す、全体・範囲再生、停止ほど狭い幅まで名前を残す。名前とショートカットはツールチップで示す。
- 詳細欄は畳める。900px未満では自動で畳み、自動で畳んだ場合だけ広げたときに元に戻す。
- 開始画面の「最近使ったフォルダ」はフォルダ履歴のダイアログ、「オプション」は分類別の設定ダイアログを開く。設定ダイアログは分類を切り替えても編集中の値を保持し、適用・OKで反映、キャンセルで破棄する。設定項目と保存処理は編集画面と共有する。

### 音声パネル

- 波形・スペクトログラム・パワー・F0の4つ。表示中のパネルだけで音声表示領域の高さ全体を使い、非表示のパネルには領域も境界も残さない。
- 単独表示は全高、複数表示は高さ設定値の比率で配分する。境界の操作は隣接パネル間の配分だけを変え、合計の高さを保つ。

### マーカーと原音設定値の色

- 原音設定値ごとに色を定義し、色に加えて名前とマーカーの形でも区別する。色は少数のテーマトークンにまとめる。ライト／ダーク切り替えは初版に含めない。
- 左右ブランクの名前は最上段に揃え、オーバーラップ・先行発声・固定範囲は別々の段に置く。右ブランクの名前は線の左側に置く。
- 固定範囲の既定色は青。波形の下半分だけを薄く塗り、スペクトログラムには塗りを重ねない。塗りはマーカーの設定色に追従する。ブランクはグレーアウトする。

## ファイルと保存

- ファイル操作は小さな共通APIにまとめ、ブラウザ版はFile System Access API、ネイティブ版はTauriのfs・dialog・persisted-scopeプラグインで実装する。共通処理には選択フォルダからの相対参照を渡し、絶対パスやブラウザのハンドルを渡さない。
- 音源をブラウザ内へコピーする仮想ファイルシステムは作らない。
- oto.iniはバイト列から読む。UTF-8とShift_JISを扱い、保存時は元の文字コードと改行を保つ。文字コードは画面から切り替えられる。行順・重複エイリアス・解釈できない行・参照先WAVがない行を保持し、未編集の行は書き換えない。正負の右ブランクと負のオーバーラップを勝手に補正しない。
- 元のoto.iniは明示保存でだけ更新する。保存前に外部変更を確認し、`oto.ini.bak`へ保存前の内容を残し、書き込み後に読み戻して一致を確かめてから保存済みにする。失敗時は未保存のまま理由を表示する。
- 別名保存ではWAVの読込元と異なるフォルダを保存先にでき、以後の保存はその保存先を使う。保存先にアクセスできなければ再選択を求め、読込元へ戻さない。
- 行コメントはiniと同じ文字コード・改行の`<ini名>-comment.txt`へ保存し、iniとまとめて外部変更の確認・バックアップ・書き込み後の照合を行う。
- WAVの加工・名前変更は実行前に確認する。元の内容を保持してから変更し、途中で失敗したら逆順に元へ戻す。戻せなかった場合はバックアップと失敗理由を知らせる。加工後は編集履歴をリセットする。
- 未保存の編集は復元データとして自動記録する。Web版はIndexedDB、ネイティブ版はアプリデータ領域のファイル。復元データは編集中の原音設定と元ファイルの識別情報（読込元・保存先の両フォルダを含む）で、音声は含まない。復元時は元ファイルの変化とフォルダへのアクセスを確認し、必要なら再選択を求める。ブラウザのサイトデータ削除後の復元は保証しない。
- 終了とフォルダ切り替えで未保存の変更があれば、保存・保存しない・キャンセルを選ばせる。
- 設定・最近使ったフォルダ・Webの復元データ・クリック音はTanStack DBの公式アダプターで保存する。設定の自動保存がOFFなら変更は起動中だけ適用し、手動保存した内容を残す。

## 処理の置き場所

- 原音設定の解釈・編集・生成、音声デコード、波形・スペクトログラム・パワー・F0の計算はWeb側に置き、Web版とネイティブ版で共有する。重い計算はWeb Workerで行う。
- Rustはプラグインの登録・権限設定と、Web公開に影響しないネイティブ専用処理（WebView2の不足検出、最前面表示、透過など）に限る。
- Tauriの権限は選択フォルダと必要な操作に絞る。

## 自動原音設定

- 日本語のCV・VCV・CVVCをSHIROで推定する。対象WAV・発音列・モデルと生成するエイリアス形式を選び、既存行の補正か生成を行う。エイリアス形式は複数選択できる。収録BPMは推定値を5刻みに丸めて初期入力し、推定値であることを示す。推定範囲は制限せず、手入力で上書きできる。詳細は[SHIRO.md](SHIRO.md)。
- 結果確認後の反映を1回のUndoで戻せる。推定だけではoto.iniを更新しない。
- 推定結果から音素ラベルをHTK単音素ラベル（WAVと同名の`.lab`を音源フォルダへ保存）として書き出せる。原音設定用の補正を含めず、原音設定への反映とは独立して保存する。

## 対象外と後続

- 対象外: 外部exe形式のプラグインの実行互換、エミュレーター、外部合成エンジンによる試聴。
- 後続: テンプレートや録音リストからの生成、音源内の複数oto.iniの横断編集、Web版のオフライン起動、ライト／ダークテーマ。
- 手動の発声タイミング補正とF8の試聴は自動推定に含めない。
