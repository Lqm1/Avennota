# 編集機能

キー・マウス操作とメニューの配置は[EDITOR-INTERACTIONS.md](EDITOR-INTERACTIONS.md)。

## 原音設定の編集

| 機能 | 内容 |
| --- | --- |
| 一覧 | 原音設定行の一覧、検索、前後の行・WAVへの移動。重複エイリアス、解釈できない行、不正な数値、参照先WAVの欠損を識別して表示する。USTや検索で絞り込んだ間はステータスバーに表示し、そこから解除できる。範囲選択・移動・一括変更は表示中の行だけを対象にする |
| 行の操作 | 追加・複製・削除、未登録WAVからの行作成。複製はコメントも引き継ぐ。同じWAVの最後の行は削除しない |
| 詳細欄 | エイリアスと5つの原音設定値の入力、コメント、右ブランク表現の切り替え |
| マーカー編集 | ドラッグ、F1〜F5の押下・保持・解放によるポインター位置への設定 |
| 連動 | 先行発声・左ブランクの連動方式。Alt操作で同じWAVの隣接行へ移動量を反映 |
| 編集の制約 | 負のオーバーラップの許可、ブランク移動の優先、右ブランク表現の全行変換 |
| 編集履歴 | Undo／Redo。ドラッグとキー保持は1操作を1回で戻す |
| セル編集 | 一覧のセルへの直接入力、矩形選択、コピー・切り取り・貼り付け、Tab・Enter・カーソルでの移動 |
| クリップボード | CSV／タブ区切りを選択。貼り付けは区切りを判別する |
| 条件付き一括変更 | 同値設定・加算・減算・整数化。一致・以上・以下の条件 |
| エイリアス一括変更 | `%m`・`%s`・`%f`・`%a`・`%r`、前後の文字削除、重複上限。対象は表示中の行・選択範囲の行・すべての行。重複上限を超えた行は後ろから削除し、同じWAVの最初の行を残す |
| 原音設定の一括処理 | 下表の5つ。対象は表示中の行・選択範囲の行・すべての行から選ぶ（複数行の選択があれば選択範囲が既定）。処理前に追加・変更・削除・スキップ・エラーの一覧を表示し、1回のUndoで戻せる。エラーの行があれば、除いて適用することを選ぶまで適用しない。表示後に編集内容が変わっていたら適用しない |
| エイリアス補完 | お→を・じ→ぢ・ず→づの複製、連続音の先行母音補完。既存・別iniのエイリアスと重複させない |
| 並び替え | 仮名・先行母音・末尾番号順、WAVファイル名順。保存時の行順も変える |
| コメント | 行ごとのコメント（一覧のエイリアス右の列と詳細欄）。コメントファイルの読み込み・書き出し。Undoと復元データに含める |
| UST連携 | 歌詞に対応する行へのコメント追記、絞り込み、対象外の行の削除。エイリアス末尾の音高などを考慮し、同じ歌詞の対象行数の上限を指定できる |
| 自動推定 | SHIROによる日本語CV・VCV・CVVCの複数形式同時生成と既存行の補正。モデル取得・差し替え、音源別の学習、仮名の訂正、index.csv・table.csvの読み込み、収録BPMの推定・推定値表示・手入力、進捗・キャンセル、結果確認と一括Undo |
| 音素ラベル | 自動推定の結果画面からHTK単音素ラベル（.lab）を音源フォルダに保存する。原音設定への反映と独立して保存 |

### 原音設定の一括処理

| 機能 | 内容 |
| --- | --- |
| 検索・置換・抽出 | エイリアス（空欄はWAV名）・WAV名・コメント・行の原文を、部分一致・完全一致・正規表現（JavaScript）で探す。大小文字の区別、直後に小書きかなが続く箇所の除外を選べる。一致行の表示を絞る（既存の絞り込みとの積）、エイリアス・コメントの置換（文字列は全箇所、正規表現は`$1`などで参照し最初か全箇所）、一致行の削除、音源フォルダの別iniへの書き出しを個別に行う。書き出しは行の元のバイト列・文字コード・改行とコメント（`<ini名>-comment.txt`）を保ち、編集中のini名には書き出さない。書き出して削除する場合は、書き出しと照合が成功してから削除する |
| 規則による複製・置換 | 「変換元,変換先」の2列の規則（入力か.ini・.csv・.txtの読み込み、UTF-8・Shift_JIS）で、エイリアスを複製して末尾へ追加するか、元の行を置換する。一致は完全一致・先頭一致（後ろの装飾を残す）・末尾一致（前の装飾を残す）・途中の一致。直後に小書きかなが続く箇所には一致しない。複製は規則順・行順で、生成した行を次の規則に使わない。置換は規則を順に重ねる。複製した行は数値の表記・追加欄・コメントを引き継ぐ |
| 重複エイリアスの整理 | UTAUで呼ばれる名前（空欄はWAV名）が完全に同じ行を、WAVが違っても1組にする。比較前に名前から除く部分を正規表現で指定できる（音階などは自動で除かない）。行ごとに残すかを選び（既定はini順で先か後の行）、ほかを削除する。各行の試聴（左ブランクから右ブランクまで）と、組の行だけを一覧に表示して波形で確認する操作がある。値やコメントは合成しない |
| 先行発声・オーバーラップの調整 | オーバーラップを先行発声の1/3にする、先行発声を指定値にしオーバーラップをその1/3にする、先行発声とオーバーラップの位置を保ち3:1にする、収録BPMに合わせる（先行発声＝8分音符、オーバーラップ＝その1/3、固定範囲＝付点8分音符、右ブランク＝4分音符＋オーバーラップの負の値）。いずれも先行発声の位置を保ち、BPM以外は固定範囲と右ブランクの終端も保つ（正の右ブランクは変えない）。新しい値の小数桁（0〜3）と、連続音（先行母音と空白で始まる行）だけの対象を選べる。左ブランク・固定範囲が負になる行、右ブランクの符号が変わる行、先行発声がオーバーラップより前にない行（3:1）はエラー |
| 連続音からCV・VCを追加 | 「a か」「- か」から音節と後ろの装飾を読み、CV（か）とVC（a k）の行を末尾へ追加する。元の行は変えない。音節表（table.csvの「音節,子音,母音,固定範囲,先行発声,オーバーラップ」）があれば表の値を使い、表にない音節は作らない。表がなければCVの先行発声・オーバーラップと子音の長さの共通値を使い、子音名は仮名の読みから決める。CVは元の先行発声の位置と右ブランクの終端を保ち、固定範囲は元の位置か表の値。元にする行は語頭の行だけか、連続音すべて（語頭を優先）。VCは先行発声の位置を子音の長さだけ前へ移して子音の始まりで終え、破裂音（k・t・p）は子音の前半で終えることを選べる |

複製・追加は、既にあるエイリアスと重なる行を既定で作らない（重複を許す設定がある）。カンマ・改行を含むエイリアスや空のエイリアスを作らない。一括の削除は、WAVの原音設定がなくなる行を「WAVの最後の行も削除する」を選んだときだけ削除する。

## 試聴

| 機能 | 内容 |
| --- | --- |
| 再生 | 全体再生、左ブランクから終端まで、表示の左端から末尾まで、停止 |
| 範囲試聴 | Ctrl+F1〜F5で開始点・終了点を設定して再生 |
| クリック操作 | 近傍マーカー間の区間再生、マーカーの中クリック再生、背景クリックで先行発声を設定する手動補正モード。区間再生と手動補正は同時に有効にしない |
| 発声タイミング試聴 | F8。テンポ、プリカウント、混合比、クリック音のWAV選択と内蔵音への復帰、選択行の連続試聴（最大20行） |
| 再生表示 | 再生位置の追従、再生開始位置への復帰 |

## 表示と解析

| 機能 | 内容 |
| --- | --- |
| 音声パネル | 波形・スペクトログラム・パワー・F0の個別表示と高さ配分。どのパネル上でもマーカーを操作できる |
| 波形 | 縦軸の上限、表示振幅 |
| スペクトログラム | FFT長8〜4096、周波数上限、窓長・窓関数・プリエンファシス、明るさ・コントラスト、配色 |
| パワー・F0 | 解析用サンプルレート、間隔・窓長・窓関数・プリエンファシス。F0はMPM（既定、pitchy）とAMDF、抽出の上下限、Hz／半音表示、音階グリッド、目標音高、固定表示範囲。窓長は抽出下限の3周期以上を確保する |
| 目標音高 | 音名の選択・試聴、ターゲット音からの解析・表示範囲の設定 |
| 横軸・時間軸 | 拡大・縮小・全体表示、スクロール。時間軸は秒／小節、BPMと開始位置 |
| 部分読み込み | フォーカス位置の前後に同じ長さの範囲をPCM WAVから読み込む。時間・マーカーは元ファイル基準。表示範囲外の試聴は全体を読み込む。自動フォーカスなしでは無効 |
| 外観 | 波形・解析・マーカー・音階グリッド・目標音高の色、フォント・文字サイズ |

F0などの表示は音声解析であり、原音設定値の自動推定は行わない。

## ファイル

| 機能 | 内容 |
| --- | --- |
| フォルダ | フォルダを開く、最近使った20フォルダ、フォルダ／iniのドロップ。ネイティブ版は親フォルダへの移動とファイルマネージャーでの表示 |
| ini | 選択フォルダ内のiniの読み込み、上書き保存、任意フォルダへの別名保存、任意ファイルへのコピー書き出し、別iniのマージ |
| WAV加工 | フォルダ全体のDC成分除去、モノラル化、指定秒数の両端カット（左右ブランクの補正を選択、相対値と負の右ブランクは保持）。F9で選択行の左ブランクから終端までを残すブランク外カット（「WAVのカットを許可」が必要） |
| WAV名変更 | アンダースコア付加。同じベース名の関連ファイルと全行の参照を更新し、名前が衝突する場合は処理しない |
| 設定 | アプリ内での保存、自動保存の切り替えと手動保存、既定値への復帰、JSON設定ファイルの読み込み・書き出し（全設定／外観／解析条件） |
| ウィンドウ | ネイティブ版の最前面表示、Windows版の透過率 |

WAV加工はPCM 8／16／24／32bitと32bit浮動小数点を読み、PCMで書き出す。音声以外のチャンクは保持しない。元ファイルの`.bak`を作る。

## 環境による違い

- ブラウザ版は親フォルダへの移動とファイルマネージャーでの表示に対応しない。
- フォルダの権限が失効した場合は再選択を案内する。
- 音声出力デバイス・レイテンシなどのオーディオI/O設定は持たない。
